# 🚀 Alexys Gómez | Software Engineer & QA Portfolio

Personal portfolio built with **Astro** and **Tailwind CSS**. Designed to showcase professional experience, certifications, and technical projects in both Spanish and English.

## 🔗 Live Demo
Check out the live version here: [https://alexysge.github.io/portafolio/](https://alexysge.github.io/portafolio/)

## 🛠️ Tech Stack
- **Framework:** [Astro](https://astro.build/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Logic:** JavaScript / Astro Components
- **Deployment:** GitHub Pages

## 📂 Project Highlights
- **Multi-language Support:** Full Spanish and English versions.
- **Glassmorphism Design:** Modern UI with subtle gradients and transparency.
- **Responsive:** Optimized for all devices.
- **QA Focused:** Highlights testing expertise and automation skills.

## 🧞 Commands
All commands are run from the root of the project:

| Command | Action |
| :--- | :--- |
| `npm install` | Installs dependencies |
| `npm run dev` | Starts local dev server at `localhost:4321` |
| `npm run build` | Build your production site to `./dist/` |
| `npm run preview` | Preview your build locally |
